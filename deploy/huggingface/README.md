# KisanSense

Decision support for farmers: tomato leaf disease check (with Grad-CAM), crop recommendation from soil and weather, and a cautious 7-day Karnataka tomato price outlook.

**Experimental. Not agricultural or financial advice.** Models are trained on public datasets (PlantVillage lab photos, a clean crop dataset, Karnataka-wide tomato prices), so real-world accuracy will be lower than the reported test scores.

Source code, results and limitations: see the GitHub repository.
