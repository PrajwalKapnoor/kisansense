# KisanSense

Decision support for farmers: tomato leaf disease check (with Grad-CAM), crop recommendation, and a cautious 7-day Karnataka tomato price outlook.

**Experimental. Not agricultural or financial advice.** Trained on public datasets (PlantVillage lab images, a clean crop dataset, Karnataka-wide Agmarknet prices), so real-world accuracy will be lower than the reported scores.

Source code, evaluation details and limitations: see the GitHub repository.
